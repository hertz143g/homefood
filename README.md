# Дома — веб-интерфейс

Отдельный Next.js-проект без базы данных, серверных маршрутов и привязки к хостингу.

## Запуск

`npm ci`
`npm run dev`

## Сборка

`npm run build`
`npm start`

В GitHub содержимое этой папки находится в корне репозитория. Для Vercel оставьте Root Directory `.` и выберите framework Next.js. Переменные базы и ключи не нужны.

## Текущее поведение

Меню, редактор, фото, ингредиенты, свайпы, турнир и календарь работают в памяти открытой страницы. Изменения полностью сбрасываются при обновлении. Данные не пишутся в localStorage, IndexedDB, файлы или базу. Фото не отправляются на сервер. Совместный доступ и приглашения убраны до подключения будущего сервера на VPS.

Проверки: `npm run typecheck`, `npm test`, `npm run build`.

## Telegram Mini App

Интерфейс подключает официальный Telegram Web App SDK, вызывает ready/expand, учитывает тему Telegram, стабильную высоту окна и безопасные отступы. Кнопка «Назад» закрывает верхний открытый экран, затем возвращает к меню. Свайпы и выбор в турнире используют лёгкую тактильную обратную связь. В обычном браузере всё работает без Telegram.

После публикации на Vercel:
1. Создайте бота через @BotFather (`/newbot`), если его ещё нет.
2. В `/mybots` выберите бота → Bot Settings → Configure Mini App. Задайте HTTPS-адрес приложения с Vercel.
3. Там же настройте Menu Button с этим адресом и подписью «Наше меню».
4. Откройте мини-приложение из бота на обоих телефонах.

Токен бота для этой подготовки не нужен. Серверная авторизация ещё не подключена: SDK используется только для интерфейса, а его наличие не считается проверкой личности. При подключении VPS сервер должен проверять подпись и срок действия Telegram `initData`, а также разрешать доступ только участникам дома. Токен бота хранится только на сервере, никогда в `NEXT_PUBLIC_*`. Данные и фотографии сейчас остаются лишь в памяти страницы. Сервера, базы и запросов к VPS пока нет.

Обложка блюда: фото или эмодзи. Фото уменьшается до 1400 пикселей на устройстве; поддерживаемый браузером файл до 20 МБ. Эмодзи можно выбрать из набора или ввести самостоятельно. Переключение вкладок сохраняет выбранное фото в черновике, но при сохранении в режиме «Эмодзи» фотография из блюда убирается.

Документация интеграции: https://core.telegram.org/bots/webapps
