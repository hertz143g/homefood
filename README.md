# Дома — веб-приложение

Отдельная веб-версия приложения «Дома». Исходный iOS-проект находится уровнем выше.

## Возможности

- Домашнее меню: карточки и список, поиск по блюдам и ингредиентам, категории, избранное, сортировка.
- Редактор: фото, ингредиенты отдельными строками, количество и единицы, наличие продуктов, варианты, порции и заметки.
- Выбор: свайпы с отменой, случайный вариант, турнир на 4/8/16 мест с проходами без соперника и сеткой до финала.
- Совместный выбор по очереди на одном телефоне; общее меню синхронизируется между телефонами каждые 6 секунд при открытом приложении.
- Необязательный план по дням; перенос на компьютере выполняется атомарно.
- Светлая/тёмная тема, анимации с учётом настройки уменьшения движения, установка на экран «Домой».

## Доступ и хранение

Первый посетитель создаёт свой дом. В разделе «Дом» он создаёт одноразовую ссылку приглашения (7 дней). Другой участник открывает её и нажимает «Присоединиться». Дом, блюда, отметки и план хранятся в D1; фотографии в R2. Каждое обращение проверяет принадлежность текущему дому. Сессия — случайный HttpOnly cookie на год, в базе только SHA-256 токена. Приглашение передаётся во фрагменте URL и удаляется из адресной строки при открытии.

В приложении нет входа через ChatGPT. У хостинга отдельно существует ограничение аудитории: пока Site закрыт владельцем, внешний посетитель не сможет открыть приложение. Снятие этого ограничения требует разрешения владельца.

Ограничения: нужен интернет; данные не кэшируются офлайн. Очистка данных браузера или истечение сессии убирает доступ с этого устройства. Автоматического восстановления аккаунта пока нет. Для второго участника владелец может выпустить новую ссылку. Не очищайте данные единственного устройства владельца. Safari и установленная веб-версия могут иметь разные сессии — приглашение следует открыть там, где планируется пользоваться приложением.

## Локальная разработка

Node.js 22.13+; `npm ci`, затем `npm run dev -- --port 5173`.
Новая локальная база требует применения SQL из `drizzle/`. Схема описана в `db/schema.ts`, доступ к базе — через `lib/server.ts`. На хостинге миграции применяет Sites.

Проверки: `npx tsc --noEmit`, `node tests/tournament.mjs`, при запущенном локальном сервере — `node tests/smoke.mjs` (создаёт тестовые дома). Smoke-проверку не запускайте против личных рабочих данных.

Публикация использует существующий Site из `.openai/hosting.json`; не создавайте новый проект. Локальные `.wrangler`, `.sites-runtime`, зависимости и cookie не входят в исходники или публикацию.
