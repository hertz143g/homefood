# Дома — Telegram Mini App

Интерфейс на Next.js размещён на Vercel, сервер и постоянные данные — на отдельном VPS. В проекте нет локальной базы, IndexedDB или сохранения меню в localStorage.

## Запуск

`npm ci`, `npm run dev`. В обычном браузере показана кнопка открытия бота. Рабочее меню доступно после проверенного входа через Telegram.

Проверки: `npm test`, `npm run typecheck`, `npm run build`; сервер — `python3 -B server/test_app.py` (БД исключительно в оперативной памяти теста).

## Telegram

Бот: https://t.me/homefoodzavbot
Приложение: https://homefood-ten.vercel.app

Кнопка меню бота открывает приложение. Первый владелец привязывается одноразовой ссылкой настройки с ограниченным сроком действия. После привязки ссылка перестаёт работать. В разделе «Дом» владелец может создать одноразовое приглашение для второго участника; оно действует 7 дней. Партнёр открывает ссылку, запускает бота и получает доступ к тому же меню. Посторонние Telegram-аккаунты не получают доступа.

Мини-приложение учитывает тему, высоту окна и безопасные отступы Telegram. «Назад» закрывает верхний экран, затем возвращает в меню. Есть виброотклик при выборе. Эмодзи выбираются из набора или с клавиатуры; фото обрабатываются на устройстве и сохраняются на VPS. Свайпы вдвоём проходят по очереди на одном телефоне.

## Сервер

- `server/app.py` — Python 3.12, стандартная библиотека, сервис `homefood.service`.
- Приложение: `/opt/homefood/app.py` на VPS.
- Данные: `/var/lib/homefood/homefood.sqlite` и `/var/lib/homefood/photos/` **только на VPS**.
- Настройки: `/etc/homefood/bot.env` и `/etc/homefood/app.env`, доступны root. systemd передаёт настройки процессу отдельного пользователя `homefood`.
- Токен бота и TLS private key находятся только на VPS. Их нет в Git и переменных браузера.
- Vercel проксирует только разрешённые маршруты через `app/api/backend/[...path]/route.ts`. Соединение зашифровано; публичный сертификат закреплён в `server/vps-certificate.ts`, проверка сертификата и IP включена. Публичная DNS-запись для VPS не требуется. При смене сертификата обновите pin и перевыпустите Vercel.
- Сервер проверяет HMAC Telegram `initData` и срок (24 часа), затем выдаёт 30-дневную сессию. Токен сессии хранится только в памяти страницы, в базе — его SHA-256. Повторное открытие приложения выполняет новый вход Telegram.
- Фото выдаются по подписанным часовым ссылкам. Сохранённая запись содержит лишь путь, новые ссылки приходят при обновлении меню.
- Обновление общего меню каждые 6 секунд. Версии записей предотвращают потерю одновременных правок; перенос в календаре выполняется в транзакции.
- Резервные копии: `server/backup.py` на VPS, `/var/backups/homefood`, ежедневные, хранятся 7 дней. Копии на том же VPS помогают восстановить ошибочное удаление, но не заменяют внешнюю копию при потере сервера.
